# SBP FieldOps — ระบบงานบริการแอร์ (สหบูรพากรุ๊ป)

โฟลเดอร์นี้เก็บ **ตัวโปรแกรม** ของระบบงานบริการเท่านั้น
ข้อมูลจริงทั้งหมด (ลูกค้า งาน ราคา ต้นทุน ผู้ใช้ รูปหน้างาน) อยู่ใน Google ชีตและ Google Drive ของบริษัท ไม่ได้อยู่ที่นี่

## ทำงานอย่างไร
1. ไฟล์ `Code.gs` (ตัวโหลด) วางไว้ใน Apps Script ของ Google ชีตฐานข้อมูล **ครั้งเดียว**
2. ตัวโหลดดึงไฟล์ระบบเวอร์ชันล่าสุดจากโฟลเดอร์นี้ (`latest.json` → `dist/`) ไปเก็บใน Google Drive ของบริษัท แล้วทำงานจากสำเนาใน Drive
3. ตรวจเวอร์ชันใหม่ทุก 10 นาที (ตัวตั้งเวลา `sbpAutoUpdate`) ไฟล์ที่ดาวน์โหลดไม่ครบ (ค่าตรวจสอบ SHA-256 ไม่ตรง) จะไม่ถูกใช้
4. ถ้า GitHub ล่ม ระบบยังทำงานต่อได้จากสำเนาใน Drive

## ห้าม
- ห้ามใส่ข้อมูลลูกค้า ราคา ต้นทุน รหัสผ่าน หรือไฟล์ข้อมูลใดๆ ในโฟลเดอร์นี้ (repo นี้เป็นสาธารณะ)
- การแก้ไฟล์ใน `dist/` หรือ `latest.json` = เปลี่ยนระบบที่ทีมใช้จริงภายใน 10 นาที

## สำหรับผู้พัฒนา
- ซอร์สอยู่ใน `src/` · ตรรกะธุรกิจ `src/supabase/functions/api/core.js` ใช้ร่วมกันทั้งเวอร์ชัน Google และ Supabase
- สร้างไฟล์: `node src/gas/build.mjs` · ทดสอบ: `BACKEND=gas node src/test/e2e.mjs`, `node src/test/gas-extra.mjs`, `BACKEND=gas node src/test/ui.mjs`
- ไฟล์ข้อมูลตั้งต้นและค่านโยบายภายในไม่อยู่ใน repo นี้
