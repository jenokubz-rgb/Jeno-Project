# SBP AirCare · เว็บไซต์ฉบับใช้งาน (Rev.09 r21 · 9 ต.ค. 2569)

ชุดนี้คือเว็บ A · B · C ฉบับแก้ไขล่าสุด แต่ละแบบเป็นไฟล์เดียว รวมราคา ฟอนต์ และภาพ 3 มิติไว้ในตัว ใช้ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรม

| โฟลเดอร์ / ไฟล์ | คืออะไร | ขึ้นเว็บสาธารณะได้ไหม |
|---|---|---|
| `web/index.html` | หน้าเลือกแบบ A / B / C | ได้ |
| `web/a.html` · `b.html` · `c.html` | เว็บไซต์ทั้ง 3 แบบ (ไฟล์ละ ~3 MB) | ได้ |
| `backoffice/backoffice.html` | หน้าหลังบ้านสำหรับทีม (ดูคำขอ ยืนยันนัด จัดทีม) | **ไม่ได้** — เปิดในเครื่องของทีมเท่านั้น |
| `backoffice/apps-script/` + `backoffice/README.md` | ระบบรับคำขอ (Google Sheet + Apps Script) และวิธีติดตั้ง | — |
| `dev/styleguide.html` | ระบบออกแบบ สำหรับทีม Dev ตรวจความสวยงาม | ไม่จำเป็น |

## 1. เปิดดูทันที

ดับเบิลคลิก `web/index.html` แล้วเลือกแบบ ใช้ได้แม้ไม่ต่ออินเทอร์เน็ต (ใช้ Chrome, Edge, Safari หรือ Firefox รุ่นปัจจุบัน)

## 2. ขึ้นเว็บจริง

1. เลือกแบบที่จะใช้ (หรือเปิดทั้ง 3 แบบระหว่างทดลอง)
2. อัปโหลดทุกไฟล์ในโฟลเดอร์ `web/` ไปที่โฮสต์เว็บแบบ static ที่เป็น **https** เช่น Cloudflare Pages, Netlify หรือโฮสติ้งของบริษัท
3. ถ้าต้องการให้แบบที่เลือกเป็นหน้าแรกของโดเมน ให้เปลี่ยนชื่อไฟล์นั้นเป็น `index.html` (แทนหน้าเลือกแบบ)

## 3. เปิดรับคำขอจริง (จองคิว · ใบเสนอราคา · ติดต่อ)

ตอนนี้เว็บ **ยังไม่ได้เชื่อมกับหลังบ้าน** เมื่อลูกค้ากดส่ง เว็บจะแสดงสรุปคำขอให้คัดลอกหรือส่งอีเมลเอง และจะไม่บอกว่า "ส่งแล้ว" (ตั้งใจไว้แบบนี้)

1. ติดตั้งหลังบ้านตาม `backoffice/README.md` ข้อ 1–7 (ใช้บัญชี Google ของบริษัท ประมาณ 15 นาที) จะได้ URL ที่ลงท้ายด้วย `/exec`
2. เปิดไฟล์เว็บที่ใช้ (เช่น `a.html`) ด้วยโปรแกรมแก้ข้อความ (Notepad หรือ VS Code) ค้นหาคำว่า `sbp-ticket-endpoint` แล้ววาง URL ลงใน `content=""` จากนั้นบันทึกไฟล์ **ไม่ต้อง build ใหม่**

   ```html
   <meta name="sbp-ticket-endpoint" content="https://script.google.com/macros/s/xxxxxxxx/exec">
   ```

3. อัปโหลดไฟล์ที่แก้แล้ว แล้วทดสอบ: ส่งคำขอ 1 รายการ ต้องเห็นเลขที่คำขอ `SBP-…` บนหน้าเว็บ มีแถวใหม่ใน Google Sheet และมีอีเมลแจ้งทีม แถบด้านบนของหน้าจะเปลี่ยนเป็น "คำขอส่งถึงทีมโดยตรง" เอง
4. ทีมเปิด `backoffice/backoffice.html` ในเครื่องตัวเอง ใส่ชื่อ รหัส `STAFF_TOKEN` และ URL `/exec` เพื่อดูคำขอ ยืนยันนัด และจัดทีม

## 4. ต้องยืนยันก่อนเปิดให้ลูกค้าจริง

- **ข้อมูลบริษัท**: ชื่อ ที่อยู่ เบอร์ อีเมล ชื่อภาษาอังกฤษ ข้อมูลชุดนี้แสดงทุกหน้า ใบประเมินราคา และข้อมูลที่ส่งให้ search engine
- **ประกาศความเป็นส่วนตัว (PDPA)**: ข้อความยินยอมในฟอร์มยังเป็นฉบับร่าง
- **ราคา**: VAT ของลูกค้าบุคคล (ยืนยันกับนักบัญชี) และวิธีปัดราคาเป็นหลักร้อย
- **แถบ "ทดลองใช้ (Beta)"** ยังอยู่บนทุกหน้า ถ้าจะเปิดจริงแบบไม่มีแถบนี้ แจ้งทีม Dev
- **ทดสอบบนมือถือจริง** อย่างน้อย Android 2 เครื่องและ iPhone 1 เครื่อง

## 5. ข้อจำกัดที่รู้แล้ว

- ไฟล์ละประมาณ 3 MB เพราะรวมทุกอย่างไว้ในไฟล์เดียว มือถือที่เน็ตช้าจะใช้เวลาโหลดครั้งแรกนานกว่าเว็บทั่วไป
- ลิงก์ Claude Artifact ใช้สำหรับทดลองเท่านั้น และส่งคำขอออกไปไม่ได้
- ค่าเดินทางคิดจากพิกัดอำเภอโดยประมาณ ทีมยืนยันกับลูกค้าอีกครั้ง
