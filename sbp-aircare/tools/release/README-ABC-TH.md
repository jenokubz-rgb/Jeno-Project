# SBP AirCare · เว็บ A · B · C ต้นฉบับ (Rev.09 r20 · 9 ต.ค. 2569)

ชุดนี้มีเฉพาะเว็บต้นฉบับ 3 แบบ ฉบับแก้ไขล่าสุด แต่ละแบบเป็นไฟล์เดียว รวมราคา ฟอนต์ และภาพ 3 มิติไว้ในตัว

| ไฟล์ | แบบ | ลูกค้าหลัก |
|---|---|---|
| `a.html` | A · Bento — สว่าง สะอาด อ่านง่าย | บ้าน คอนโด ร้านเล็ก |
| `b.html` | B · Engineering Sheet — เอกสารวิศวกรรม ตรวจสอบได้ | องค์กร ฝ่ายอาคาร |
| `c.html` | C · Virtual Showroom — โชว์รูมมืด เน้นสินค้าและภาพ 3 มิติ | คนเลือกซื้อแอร์ |

## 1. เปิดดู

ดับเบิลคลิกไฟล์ที่ต้องการ ใช้ได้แม้ไม่ต่ออินเทอร์เน็ต (Chrome, Edge, Safari หรือ Firefox รุ่นปัจจุบัน) · สลับแบบได้จากปุ่ม A B C ที่หัวเว็บ (จอคอมและแท็บเล็ต)

## 2. ขึ้นเว็บจริง

1. เลือกแบบที่จะใช้
2. เปลี่ยนชื่อไฟล์นั้นเป็น `index.html` แล้วอัปโหลดไปที่โฮสต์เว็บแบบ static ที่เป็น **https** (Cloudflare Pages, Netlify หรือโฮสติ้งของบริษัท) — ถ้าจะเปิดทั้ง 3 แบบ อัปโหลดทั้ง 3 ไฟล์ด้วยชื่อเดิม
3. ถ้าขึ้นเว็บแบบเดียว ปุ่มสลับ A B C ที่หัวเว็บจะลิงก์ไปแบบที่ไม่ได้อัปโหลด — แจ้งทีม Dev ให้ซ่อนปุ่มนี้ก่อนเปิดจริง

## 3. เปิดรับคำขอจริง (จองคิว · ใบเสนอราคา · ติดต่อ)

ตอนนี้ **ยังไม่ได้เชื่อมกับหลังบ้าน** เมื่อลูกค้ากดส่ง เว็บแสดงสรุปคำขอให้คัดลอกหรือส่งอีเมลเอง และจะไม่บอกว่า "ส่งแล้ว"

1. ติดตั้งหลังบ้าน (Google Sheet + Apps Script ด้วยบัญชีบริษัท ~15 นาที) ตาม `sbp-aircare/backoffice/README.md` ใน GitHub (ไฟล์ชุดเดียวกับในโฟลเดอร์ `backoffice/` ของ zip ฉบับเต็มที่ส่งก่อนหน้า) จะได้ URL ลงท้ายด้วย `/exec`
2. เปิดไฟล์เว็บด้วยโปรแกรมแก้ข้อความ (Notepad หรือ VS Code) ค้นหา `sbp-ticket-endpoint` วาง URL ลงใน `content=""` แล้วบันทึก **ไม่ต้อง build ใหม่**

   ```html
   <meta name="sbp-ticket-endpoint" content="https://script.google.com/macros/s/xxxxxxxx/exec">
   ```

3. อัปโหลดไฟล์ที่แก้แล้ว ทดสอบส่งคำขอ 1 รายการ ต้องเห็นเลขที่คำขอ `SBP-…` บนหน้าเว็บ มีแถวใหม่ใน Google Sheet และอีเมลแจ้งทีม · แถบด้านบนเปลี่ยนเป็น "คำขอส่งถึงทีมโดยตรง" เอง

## 4. ต้องยืนยันก่อนเปิดให้ลูกค้าจริง

- ข้อมูลบริษัท (ชื่อ ที่อยู่ เบอร์ อีเมล) — แสดงทุกหน้าและในใบประเมินราคา
- ประกาศความเป็นส่วนตัว (PDPA) — ข้อความยินยอมในฟอร์มยังเป็นฉบับร่าง
- ราคา: VAT ของลูกค้าบุคคล (ยืนยันกับนักบัญชี) และวิธีปัดหลักร้อย
- แถบ "ทดลองใช้ (Beta)" ยังอยู่บนทุกหน้า ถ้าจะเปิดจริงแบบไม่มีแถบ แจ้งทีม Dev
- ทดสอบบนมือถือจริง อย่างน้อย Android 2 เครื่องและ iPhone 1 เครื่อง

## 5. ข้อจำกัด

- ไฟล์ละประมาณ 3 MB เน็ตช้าจะโหลดครั้งแรกนานกว่าเว็บทั่วไป
- ค่าเดินทางคิดจากพิกัดอำเภอโดยประมาณ ทีมยืนยันกับลูกค้าอีกครั้ง
